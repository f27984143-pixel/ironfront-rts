# Ironfront RTS

RTS 3D táctico en el navegador con control directo de unidades, IA de combate, vehículos terrestres y aéreos, y ataque aéreo.

## ¿Qué incluye?

- Soldados con IA táctica (cobertura, flanqueo)
- Tanques, APC, helicópteros, transportes y botes
- 5 armas con recarga y sobrecalentamiento
- Control directo de cualquier unidad (tecla C)
- Ataque aéreo con jets
- Zona de captura

## Cómo se juega

- **Cámara:** Q/E para girar, arrastrar para panorámica
- **Zoom:** rueda del ratón
- **Selección:** clic izquierdo en una unidad
- **Órdenes:** clic en el terreno
- **Control directo:** tecla C
- **Armas:** teclas 1-5
- **Recargar:** tecla R

## Tecnología

HTML + JavaScript puro con Three.js. Todos los assets son generados por código.
